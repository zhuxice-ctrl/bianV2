# 交易系统文档 — Price Action Confluence

## 1. 系统定位

本交易系统基于**价格行为学 (Price Action)** 理念，通过阅读 K 线结构中的多空力量，在关键位置结合形态确认顺势进场。系统不依赖滞后指标的超买超卖信号，而是直接解读价格本身的供需博弈。

**适用市场**：加密货币 BTC / ETH / BNB
**适用周期**：4H 主交易周期
**交易类型**：现货 / 合约均可（策略逻辑一致，合约需额外考虑资金费率）

---

## 2. 四层信号架构

### 第一层：主趋势过滤 (EMA200)

EMA200 是市场长期成本线，作为多空环境的分水岭：

- 收盘价 > EMA200 → 多头环境，**只做多**
- 收盘价 < EMA200 → 空头环境，**只做空**

**作用**：过滤逆势交易，确保在大趋势方向操作。加密市场趋势性强，顺势交易概率显著高于逆势。

### 第二层：次级趋势确认 (EMA20 / EMA50)

在主趋势方向内，用快慢 EMA 交叉结构确认中短期趋势：

- EMA20 > EMA50 且价格 > EMA20 → 上升趋势确认
- EMA20 < EMA50 且价格 < EMA20 → 下降趋势确认

**作用**：双重趋势同向时才产生交易信号，提高胜率。只有主趋势和次级趋势同向时，才算高概率交易环境。

### 第三层：价格行为形态信号

在趋势确认后，等待价格行为形态出现作为进场触发器。系统识别三种核心形态：

#### Pin Bar（针杆 / 锤子线）
长影线表示价格被拒绝，是关键位置的供需反转信号。

- 影线长度 ≥ 0.6 × ATR
- 实体 ≤ 全高的 35%
- 下影线长 → 看多信号；上影线长 → 看空信号

#### Engulfing（吞没形态）
后一根 K 线实体完全包住前一根，表示多空力量反转。

- 看多吞没：前阴后阳，阳实体包住阴实体
- 看空吞没：前阳后阴，阴实体包住阳实体

#### Break of Structure（结构突破）
价格突破近期 swing 高/低点，确认趋势延续。

- 突破 swing high → 看多
- 突破 swing low → 看空

**融合规则**：主趋势 + 次级趋势 + 任一形态信号同向 → 产生有效交易信号。

### 第四层：风险管理

| 参数 | 值 | 说明 |
|------|-----|------|
| 单笔风险 | 2% 资金 | 每笔交易最多亏损总资金的 2% |
| 止损距离 | 1.5 × ATR | 基于波动率自适应，高波动时止损更宽 |
| 止盈距离 | 3 × 风险 | 1:3 盈亏比，覆盖低胜率 |
| 波动率过滤 | ATR/Close 0.5%~5% | 避开极端行情和死水盘整 |
| 手续费 | 0.04% (taker) | 已计入回测 |
| 滑点 | 0.05% | 已计入回测 |

## 3. 进场逻辑

当四层信号全部满足时：

1. 检查当前 K 线收盘后的趋势状态
2. 主趋势(EMA200) + 次级趋势(EMA20/50) 同向
3. 波动率在合理区间
4. 出现 Pin Bar / Engulfing / BOS 任一形态
5. **下一根 K 线开盘价进场**（避免未来函数）

做多示例：
- BTC 收盘价 > EMA200（多头环境）
- EMA20 > EMA50 且价格 > EMA20（上升趋势）
- 出现看多 Pin Bar（下影线拒绝）
- → 下一根 K 线开盘做多

---

## 4. 出场逻辑

进场后逐根 K 线检查两个出场条件：

- **止损出场**：价格触及 1.5×ATR 止损位 → 亏损平仓
- **止盈出场**：价格触及 3 倍风险止盈位 → 盈利平仓
- **数据结束**：回测结束时未触发则按收盘价平仓

同一时间只持有一个仓位，避免重叠风险。

## 5. 回测验证

### 回测配置

- 数据：Binance 真实历史 4H K 线，约 1 年（2190 根）
- 初始资金：10,000 USDT
- 周期：2025-07 至 2026-07

### 回测结果

#### BTC
- 总收益：+27.85%（10,000 → 12,784 USDT）
- 交易数：63 笔（21 胜 / 42 负）
- 胜率：33.33%
- 盈亏比 PF：1.247
- 最大回撤：-17.64%
- 平均盈利：670 USDT / 平均亏损：-269 USDT
- 平均持仓：19 根 K 线（约 3.2 天）

#### ETH
- 总收益：+16.04%（10,000 → 11,604 USDT）
- 交易数：61 笔（18 胜 / 43 负）
- 胜率：29.51%
- 盈亏比 PF：1.128
- 最大回撤：-28.37%

#### BNB
- 总收益：-7.39%（10,000 → 9,261 USDT）
- 交易数：65 笔（17 胜 / 48 负）
- 胜率：26.15%
- 盈亏比 PF：0.938
- 最大回撤：-23.61%

### 结果分析

- BTC 和 ETH 在策略下实现正收益，验证了价格行为学融合策略的趋势捕获能力
- 1:3 盈亏比设计使低胜率（~30%）仍可盈利——趋势跟随策略的典型特征
- BNB 表现较弱，可能因其波动特性与 EMA200 趋势过滤适配度较低
- 胜率 26-33% 符合趋势跟随策略的预期区间（盈亏平衡点 = 1/(1+3) = 25%）

## 6. 已知局限

1. **回测周期**：约 1 年数据，覆盖的市场环境有限
2. **BNB 适配**：当前参数对 BNB 优化不足，可针对不同品种调参
3. **资金费率**：合约回测未计入资金费率成本
4. **流动性**：大资金交易需考虑滑点放大
5. **参数过拟合**：EMA 周期和 ATR 倍数需在更多数据上验证稳健性

---

## 7. 扩展方向

- **多周期共振**：日线趋势 + 4H 信号 + 1H 精准进场
- **动态止盈**：盈利后用移动止损锁定利润
- **品种适配**：为不同币种训练独立参数集
- **机器学习**：用形态特征训练进场质量分类器
- **实盘对接**：通过 ccxt 连接交易所 API 实盘执行
