# ETH 市场周期加权单币策略研究设计

## 目标

交付首个可复现的单币策略研究垂直切片：对 `ETHUSDT` 的既有 4 小时价格行为策略，以 100U 初始资金对比原始策略与市场周期置信度加权策略。系统仅生成只读研究结论、审计 artifact 和页面展示；不读取交易所密钥、不创建订单、不调用私有交易接口，也不触发任何下载或回测操作。

这条切片的目的不是证明策略盈利，而是验证市场周期作为风险乘数是否能改善 ETH 策略的风险收益特征，并建立未来添加 BTC、BNB 或替换策略时无需重构既有终端的契约边界。

## 已固定的策略规则

首期复用 `strategies.price_action.confluence_signals` 和 `bian_quant.signals.legacy_pa.adapt_confluence_signals`，不在本次回测中调整参数或搜索参数。

- 标的：`ETHUSDT`；4 小时 OHLCV。
- 信号：EMA200 主趋势、EMA20/EMA50 次趋势、Pin Bar／吞没／结构突破与 ATR 波动过滤的既有组合信号。
- 方向：保留现有多空信号。
- 风控：ATR 的 1.5 倍止损、1:3 止盈；同 K 线止损／止盈冲突按既有回测引擎的 `STOP_FIRST` 规则处理。
- 成交：信号由已收盘 K 线产生，下一根 K 线开盘成交；手续费、滑点和期末平仓均使用现有引擎的显式配置。
- 资本：每个变体独立从 100.00U 开始，比较结果不共享资金，也不表示组合仓位。

## 因果性与市场周期加权

市场周期状态沿用当前热门池证据计算方法。对任一 4 小时信号，适配器只能使用信号决策时刻或之前已发布的热门池记录；不能读取当日之后的热门池、价格、收益或最终标签。

原始策略对每次有效信号申请固定的 100U 名义上限。加权策略保持相同的信号方向、入场、止损、止盈、手续费和滑点，仅把该次申请名义金额乘以决策时刻的周期风险系数：

- `bull` 且置信度 >= 0.80：1.00；
- 非 `risk_off` 且置信度 >= 0.65：0.70；
- 非 `risk_off` 且置信度 >= 0.50：0.40；
- `risk_off`、置信度 < 0.50 或证据不足：0.00。

零系数表示不参与新的信号；它不修改已由策略开出的历史交易。此规则与既有共享仓位分配的阈值一致，但单币评估不读取或改变三币共享 allocation。

## 契约拓扑与演进边界

`GET /api/research/latest` 保持 HTTP 200、既有字段和 `research-terminal-v1` 不变。响应新增默认空列表的可选扩展节点 `single_asset_strategy_evaluations`，使旧消费者仍能安全忽略新字段。

```text
ResearchTerminalResponse
  └─ single_asset_strategy_evaluations[]       稳定前后端契约
       └─ 单币评估聚合器                        每个注册评估器一个实现
            ├─ ETH PA 策略适配器                信号、周期乘数、回测输入
            ├─ 市场周期证据服务                 决策时点以前的热门池记录
            ├─ 既有回测引擎                     成交、费用、止损与权益
            └─ JSON artifact                    输入、结果与 SHA-256 审计
```

协议模型只定义稳定的数据形状；聚合器只编排注册评估器并防御性映射 artifact；策略适配器只把指定币种的已落盘数据转换为回测输入。页面仅消费契约节点，不导入策略逻辑或读取 artifact。因此后续新增 BTC／BNB、增加不同策略版本或删除一项实验，均是新增／替换评估实现和一个列表项，不修改既有研究状态、市场周期、三币 allocation 或原有 100U 对比字段。

## 单币评估契约

每一项 `SingleAssetStrategyEvaluation` 包含：

- `asset`：首期固定为 `ETHUSDT`。
- `strategy_id` 与 `strategy_version`：首期为 `legacy.pa_confluence`／`baseline-0`。
- `status`：`ok`、`missing` 或 `error`；单币不可用不得把整轮研究状态从 `passed` 改为 `blocked`。
- `sample_start`、`sample_end`、`generated_at`、`runtime_ms`：样本和运行审计信息。
- `input_artifact_sha256`、`result_artifact_sha256`、`artifact_path`：canonical JSON 的输入／结果哈希与相对路径。
- `current_signal`：`long`、`short`、`flat` 或 `unavailable`，另含决策时间。
- `market_cycle`：当前周期标签、置信度、风险系数和证据哈希。
- `recommendation`：`participate` 布尔值、最大建议投入（U）和机器可读原因；参与条件为当前信号非 flat、周期系数大于零且证据状态可用。
- `baseline` 与 `confidence_weighted`：同一 `StrategyMetrics` 形状，均包括期末权益、总收益、最大回撤、胜率、已平仓交易次数、手续费后净利润与已付手续费。

指标都以费用后结果为准。没有成交时，胜率为 `null` 而不是伪造 0%；期末权益仍报告 100.00U。`error` 条目返回结构完整的零／空审计值和可读错误摘要，不抛出 API 异常。

## Artifact 与数据边界

单币结果写入最新研究运行目录的独立文件，例如 `single-asset-strategies/ethusdt-legacy-pa-confluence.json`。artifact 使用 canonical JSON（键排序、紧凑分隔符、UTF-8）计算 SHA-256，并包含：契约版本、策略标识、固定参数、回测成本参数、样本区间、输入 OHLCV 哈希、市场周期证据哈希、两种变体的指标、当前建议和生成耗时。

聚合器只读取已有本地原始 K 线与热门池 artifact。缺少 ETH 4 小时数据、样本少于策略预热需求、市场周期证据不能计算或 artifact 解析失败时，写入／映射为 `missing` 或 `error`；不填补、前向填充或合成数据。单币失败独立显示，不影响热门币数据准备的硬阻断规则。

## 研究页

在现有市场周期与三币对比区域之后新增「ETH 单币策略对比」面板，仍沿用黑绿终端视觉和只读限制。

- 首行用自然语言说明：当前市场判断、ETH 是否建议参与、最多建议投入多少 U 和原因。
- 第二行并列展示原始／置信度加权的期末权益、收益、最大回撤、胜率、交易次数和费用后净利润；风险下降与收益变化使用清晰的正负色，但不宣称预测或保证收益。
- 显示当前信号、策略版本、样本区间、市场周期风险系数、运行时间与 artifact SHA 前缀；完整哈希保留在可展开审计详情中。
- `missing`／`error` 显示“当前无法评估”的原因与影响，不显示虚假建议；页面不增加运行、下载、下单或参数编辑按钮。

## 验收标准

1. API 对旧的 `passed`、`blocked` 与 `empty` 研究运行继续返回完整且兼容的旧字段，并始终额外返回列表类型的 `single_asset_strategy_evaluations`。
2. ETH 切片对固定 OHLCV 和热门池 fixture 产出确定的两组 100U、费用后指标和 canonical artifact 哈希。
3. 任意 t 时刻的周期加权结果对 t 之后热门池记录或价格收益的变化保持不变；信号只在下一根 K 线成交。
4. 两个变体使用完全一致的策略信号／退出规则；差异仅为风险系数造成的信号名义上限。
5. 当前建议能明确解释参与状态、建议最大投入和原因；`risk_off`、低置信度或无当前信号时为 0U 且不参与。
6. 缺少数据或证据时，ETH 项目独立降级为 `missing`／`error`，不改变热门币研究状态或伪造结果。
7. 页面在桌面和窄屏下可读取此模块，并继续明确显示 `READ-ONLY · RESEARCH ONLY · NO LIVE TRADING`。
8. 新增单元／聚合器测试、相关规范检查、类型检查和 API／浏览器烟雾检查均通过。

## 非目标

- 本阶段不实现 BTC、BNB 或多币合并回测。
- 不优化、搜索或调参价格行为策略；也不声明其具有稳定超额收益。
- 不接入纸面下单、交易所 API、API Key、私有接口或真实资金。
- 不将单币结果用于改变现有三币共享仓位建议或热门币数据准备状态。
- 不自动重跑数据准备或回测；研究页面刷新仅重新读取 API。

## 失败处理界限

实现与验证中，同一具体问题最多尝试三次。若仍未解决，交付记录必须说明问题原因、用户／研究影响、可复现命令或步骤，以及建议的下一步；不得进入无限修复循环。
