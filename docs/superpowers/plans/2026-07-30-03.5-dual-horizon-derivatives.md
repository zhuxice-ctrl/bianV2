# Dual-Horizon Derivatives Evidence Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build immutable five-year Macro and two-year Micro Binance USD-M datasets, run real Funding/OI factor validation without look-ahead, and produce append-only decision artifacts that remain useful even when no factor is promoted.

**Architecture:** Extend the existing Plan 01 raw/catalog contracts instead of creating a second lake. A resumable acquisition plan downloads exact monthly or daily source objects into `var/`, canonical parsers preserve event and availability time, and deterministic snapshot builders publish Macro and Micro Parquet datasets. Plan 02 experiment and holdout contracts govern the run; Plan 03 factor registry and evaluation code govern promotion.

**Tech Stack:** Python 3.11, Pydantic, pandas/NumPy/SciPy, PyArrow/Parquet, SQLite, Typer, urllib, pytest/Hypothesis, uv, Binance public USD-M archives.

```python
class SourceDataset(StrEnum):
    OHLCV = "ohlcv"
    FUNDING = "funding"
    METRICS_OI = "metrics_oi"


class SourceGranularity(StrEnum):
    MONTHLY = "monthly"
    DAILY = "daily"


@dataclass(frozen=True, order=True)
class SourceObject:
    dataset: SourceDataset
    asset: str
    interval: str
    granularity: SourceGranularity
    period_start: datetime
    url: str
    relative_path: Path

    @property
    def identity_key(self) -> str:
        return "|".join(
            (
                self.dataset.value,
                self.asset,
                self.interval,
                self.granularity.value,
                self.period_start.isoformat(),
            )
        )

    @property
    def raw_identity(self) -> RawSourceIdentity:
        return RawSourceIdentity(
            asset=self.asset,
            dataset=self.dataset.value,
            interval=self.interval or None,
            source_period=self.period_start.strftime(
                "%Y-%m" if self.granularity == SourceGranularity.MONTHLY else "%Y-%m-%d"
            ),
        )


def build_source_plan(config: DualHorizonAcquisition) -> tuple[SourceObject, ...]: ...
```

Rules are exact: monthly OHLCV for union `{1d, 4h}` from Macro start and `1h`
from Micro start; daily OHLCV for the incomplete July tail; monthly plus daily
tail Funding from Macro start; daily Metrics/OI only from Micro start. Deduplicate
the shared 4h request, reject any object later than cutoff, build URLs using the
adapter functions, and sort by dataset/asset/interval/period.
