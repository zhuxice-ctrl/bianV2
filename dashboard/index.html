CORE IDEA 抛弃滞后指标，直接阅读 K 线结构中的多空力量

交易系统由 主趋势过滤 → 次级趋势确认 → 形态信号 → 风险管理 四层构成，全部条件同向时才在下一根 K 线开盘价进场（避免未来函数）。

LAYER 1 — 主趋势过滤 (EMA200)

  • 收盘价在 EMA200 之上 = 多头环境，只做多
  • 收盘价在 EMA200 之下 = 空头环境，只做空

LAYER 2 — 次级趋势确认 (EMA20/50)

  • EMA20 > EMA50 且价格在 EMA20 之上 = 上升趋势
  • EMA20 < EMA50 且价格在 EMA20 之下 = 下降趋势

LAYER 3 — 价格行为形态信号

  • Pin Bar (针杆)：长影线拒绝，影线 ≥ 0.6×ATR，实体 ≤ 35% 全高
  • Engulfing (吞没)：实体完全包住前一根 K 线实体
  • Break of Structure (结构突破)：突破近期 swing 高/低点

LAYER 4 — 风险管理

  • 单笔风险 2% · 止损 1.5 × ATR · 止盈 1:3 盈亏比
  • 波动率过滤：ATR/Close ∈ [0.5%, 5%]
  • 成本：手续费 0.04% + 滑点 0.05%（已计入回测）
